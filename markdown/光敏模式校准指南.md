# 光敏模式校准指南

## 电路原理

```
3.3V ──┬── 100KΩ ──┬── ADC(PA12) ── GL5506 ── GND
       │           │
       └───────────┘
```

GL5506 是光敏电阻：**暗阻大、亮阻小**。

| 环境 | GL5506 阻值 | ADC 读数 |
|------|------------|---------|
| 全黑（深夜） | ~1MΩ | **~3700** |
| 昏暗（黄昏） | ~50KΩ | **~2000** |
| 明亮（白天） | ~10KΩ | **~400** |
| 车灯直射 | ~500Ω | **~100** |

ADC 是 **12 位**（0~4095），值越大代表越暗。

---

## 核心公式：百分比 ↔ ADC 转换

App 上的滑块选择 **0~100%**，固件将其转换为 ADC 阈值：

```
threshold_adc = 4095 - (threshold_percent × 4095 ÷ 100)
```

| 滑块值 | 对应环境 | ADC 阈值 | 含义 |
|--------|---------|---------|------|
| 0% | 深夜 | 4095 | 极暗才开灯 |
| 25% | 黎明 | 3071 |  |
| **50%** | **黄昏** | **2048** | **出厂默认** |
| 75% | 阴天 | 1024 |  |
| 100% | 白天 | 0 | 稍微暗点就开灯 |

**转换逻辑**：百分比刻度是**反向**的——0% 对应最暗（ADC=4095），100% 对应最亮（ADC=0）。

> 原因：用户觉得 0%→100% 是"从无到有"，而 ADC 读数 0→4095 是"从亮到暗"。
> 公式取反后，滑块往左拉=更暗才开灯，往右拉=更亮就开灯，符合直觉。

---

## 滞回区间（防抖）

为避免 ADC 在临界点抖动导致灯频繁开关，固件使用**滞回比较**：

```
开灯阈值 = threshold_adc + 500   （暗到超过这个值 → 开灯）
关灯阈值 = threshold_adc - 500   （亮到低于这个值 → 关灯）
```

**举例**：滑块在 50%（threshold_adc=2048）

```
开灯：ADC > 2548  → 开灯（环境变暗到超过黄昏程度）
关灯：ADC < 1548  → 关灯（环境变亮到超过黄昏程度）

         ┌── 开灯区（暗）
         │
   2548  ┤─── 开灯阈值 (2048 + 500)
   2048  ┤─── 滑块设定的中点
   1548  ┤─── 关灯阈值 (2048 - 500)
         │
         └── 关灯区（亮）
```

500 的滞回区间 ≈ 12% 的 ADC 范围，有效防止 LED 灯光→LDR 反馈→反复开关的振荡。

---

## 防抖计数 + 锁定时间（三重防振荡）

| 机制 | 参数 | 作用 |
|------|------|------|
| 滞回比较 | ±500 ADC | 开关阈值分离 |
| 防抖计数 | 连续 3 次 | 避免单次噪声触发 |
| 锁定时间 | 开灯后 30 秒 / 关灯后 10 秒 | 防止灯光→LDR 反馈回路 |

---

## 开灯亮度

自动开灯时使用的亮度百分比，直接传给调光函数：

```
gen_level_force_set_percent(on_brightness)
```

| 设定值 | 效果 |
|--------|------|
| 1% | 微亮（夜间不刺眼） |
| 50% | 半亮 |
| 100% | 全亮（默认） |

> 注：1% 是最低值，0% 会被自动提升到 100% 防止"开灯=关灯"。

---

## 现场校准步骤

1. 在 App 光敏模式卡片中点击**读取状态**
2. 观察固件串口日志中的 `ADC=xxxx` 值
3. 根据当前环境判断理想 ADC 值：

   | 你希望的效果 | 对应 ADC | App 滑块值 |
   |------------|---------|-----------|
   | 完全黑了才开灯 | ADC≈3500 | ~15% |
   | 黄昏时开灯（推荐） | ADC≈2000 | ~50% |
   | 阴天就开灯 | ADC≈1000 | ~75% |
   | 稍微变暗就开灯 | ADC≈500 | ~90% |

4. 将滑块拖到对应位置松手即可
