# 多普勒雷达频移公式解释

多普勒雷达常用的频移公式是：

```text
f_d = 2v / λ
```

其中：

- `f_d`：多普勒频移，单位 Hz
- `v`：目标沿雷达视线方向的速度，单位 m/s
- `λ`：雷达电磁波波长，单位 m

## 为什么是 `v / λ`

电磁波的频率可以理解为：单位时间内经过某一点的波峰数量。

如果目标正在靠近雷达，目标每秒向雷达方向移动 `v` 米。波长是 `λ` 米，也就是说每移动 `λ` 米，就相当于多跨过一个波峰。

所以目标运动引起的频率变化量和下面这个量成正比：

```text
每秒跨过的波峰数 = v / λ
```

因此，对于一次传播过程，多普勒频移可以理解为：

```text
f_d ≈ v / λ
```

## 为什么雷达里是 `2v / λ`

雷达不是只接收目标自己发出的波，而是：

```text
雷达发射电磁波 → 打到目标 → 目标反射回雷达
```

也就是说，运动目标会影响两段传播：

1. 雷达波从雷达到目标时，目标在运动，目标“接收到”的频率已经发生一次多普勒变化。
2. 目标再把波反射回雷达时，相当于一个运动的反射源，又发生一次多普勒变化。

所以雷达测到的是“去程 + 回程”两次多普勒效应叠加：

```text
f_d = v / λ + v / λ
```

因此得到：

```text
f_d = 2v / λ
```

## 直观理解

可以把雷达波想象成一排排等间距的波峰，间距就是 `λ`。

目标靠近雷达时：

- 去程时，目标每秒多迎上 `v / λ` 个波峰；
- 回程时，反射波又因为目标靠近雷达而每秒多压缩 `v / λ` 个波峰；
- 两次加起来就是 `2v / λ`。

所以雷达多普勒频移比普通“单程”多普勒多一个 2 倍。

## 方向问题

严格来说，公式里的 `v` 指的是目标沿雷达视线方向的速度分量，也叫径向速度。

如果目标不是正对雷达运动，而是与雷达视线方向有夹角 `θ`，则只有速度在雷达方向上的分量会产生多普勒频移：

```text
v_r = v cosθ
```

此时公式变成：

```text
f_d = 2v_r / λ = 2v cosθ / λ
```

如果目标横向运动，`θ = 90°`，那么 `cosθ = 0`，径向速度为 0，理论上不会产生多普勒频移。

## 和发射频率的关系

波长和发射频率满足：

```text
λ = c / f_c
```

其中：

- `c`：光速，约为 `3 × 10^8 m/s`
- `f_c`：雷达载波频率

所以公式也可以写成：

```text
f_d = 2v f_c / c
```

这说明：

- 目标速度越大，多普勒频移越大；
- 雷达频率越高，波长越短，同样速度产生的频移越大；
- 24 GHz、60 GHz、77 GHz 这类毫米波雷达更容易测到小速度变化。

## 例子

假设雷达频率是 24 GHz：

```text
λ = c / f_c = 3 × 10^8 / 24 × 10^9 = 0.0125 m
```

如果目标以 `1 m/s` 的径向速度靠近雷达：

```text
f_d = 2v / λ = 2 × 1 / 0.0125 = 160 Hz
```

也就是说，雷达接收到的回波频率会相对发射频率偏移约 `160 Hz`。
