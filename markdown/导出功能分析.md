# 你的 app 导出功能分析

## 当前实现

```kotlin
// MeshViewModel.kt
fun exportMeshNetwork(): String? {
    return try {
        MeshState.meshManagerApi.exportMeshNetwork()
    } catch (e: Exception) { null }
    }
}

// SettingsActivity.kt
private fun exportMeshConfig(uri: Uri) {
    val json = viewModel.exportMeshNetwork()
    if (json == null) {
        Toast.makeText(this, "导出失败：网络未加载或为空", Toast.LENGTH_LONG).show()
        return
    }
    
    try {
        contentResolver.openOutputStream(uri)?.use { outputStream ->
            outputStream.write(json.toByteArray())
        }
        Toast.makeText(this, "导出成功", Toast.LENGTH_SHORT).show()
    } catch (e: Exception) {
        Toast.makeText(this, "写入文件失败: ${e.message}", Toast.LENGTH_LONG).show()
    }
}
```

## 分析结果

### ✅ 优点

1. **使用官方 API**：`meshManagerApi.exportMeshNetwork()` 是 nRF Mesh 库的标准导出方法
2. **格式正确**：应该会导出符合 Bluetooth Mesh 规范的 JSON 格式
3. **包含完整信息**：理论上包含所有必需字段

### ⚠️ 潜在问题

#### 问题 1：导出的数据可能不完整

**原因**：nRF Mesh 库只导出**当前数据库中的数据**

```
你的 app 数据库:
├── NetKey: 21AC2505...
├── AppKey: E644AEE8...
├── Provisioner: 0x0099
└── Nodes: 
    └── Provisioner 节点 (0x0099)
    └── ❌ 没有 nRF Mesh 配网的设备！

nRF Mesh app 数据库:
├── NetKey: XXXXXXXX...
├── AppKey: YYYYYYYY...
├── Provisioner: 0x0001
└── Nodes:
    ├── Provisioner 节点 (0x0001)
    ├── 灯1 (0x0011) ✅
    ├── 灯2 (0x0012) ✅
    └── 灯3 (0x0013) ✅
```

**结果**：
- 你的 app 导出的 JSON **不包含** nRF Mesh 配网的设备
- 因为这些设备不在你的 app 数据库中

#### 问题 2：NetKey 和 AppKey 不同

```json
// 你的 app 导出
{
  "netKeys": [{"key": "21AC250562E2882B93C3BCCD6B9873CE"}],
  "appKeys": [{"key": "E644AEE801985C7BEDF296E57353B36F"}]
}

// nRF Mesh 导出
{
  "netKeys": [{"key": "XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX"}],  // 不同！
  "appKeys": [{"key": "YYYYYYYYYYYYYYYYYYYYYYYYYYYYYYYY"}]   // 不同！
}
```

**结果**：
- 即使你导出了配置，也无法控制 nRF Mesh 配网的设备
- 因为密钥不匹配

#### 问题 3：异常处理不够详细


### 2. 没有验证导出的 JSON 是否完整

**问题**：导出可能成功，但数据不完整

**建议**：添加验证功能

```kotlin
fun validateExportedJson(json: String): Boolean {
    return try {
        val jsonObject = JSONObject(json)
        
        // 检查必需字段
        val hasSchema = jsonObject.has("\$schema")
        val hasVersion = jsonObject.has("version")
        val hasMeshUUID = jsonObject.has("meshUUID")
        val hasNetKeys = jsonObject.has("netKeys")
        val hasAppKeys = jsonObject.has("appKeys")
        val hasProvisioners = jsonObject.has("provisioners")
        val hasNodes = jsonObject.has("nodes")
        
        val isValid = hasSchema && hasVersion && hasMeshUUID && 
                      hasNetKeys && hasAppKeys && hasProvisioners && hasNodes
        
        if (!isValid) {
            Log.w("MeshApp", "导出的 JSON 缺少必需字段")
        }
        
        isValid
    } catch (e: Exception) {
        Log.e("MeshApp", "JSON 验证失败: ${e.message}")
        false
    }
}
```

### 4. 没有导出后的验证

**问题**：导出的文件可能损坏或不完整

**建议**：导出后立即验证

```kotlin
private fun exportMeshConfig(uri: Uri) {
    val json = viewModel.exportMeshNetwork()
    if (json == null) {
        Toast.makeText(this, "导出失败：网络未加载或为空", Toast.LENGTH_LONG).show()
        return
    }
    
    // ✅ 验证 JSON 格式

    }
    
    try {
        contentResolver.openOutputStream(uri)?.use { outputStream ->
            outputStream.write(json.toByteArray())

        // ✅ 显示导出摘要
        val summary = viewModel.getExportSummary()
        Toast.makeText(this, "导出成功\n$summary", Toast.LENGTH_LONG).show()
        
    } catch (e: Exception) {
        Toast.makeText(this, "写入文件失败: ${e.message}", Toast.LENGTH_LONG).show()
    }
```

## 核心问题总结

### 你的 app 导出功能本身没有问题

**nRF Mesh 库的 `exportMeshNetwork()` 会导出完整的 JSON 格式**，包括：
- ✅ 所有必需字段
- ✅ NetKeys 和 AppKeys
- ✅ Provisioner 信息
- ✅ 所有已配网设备的 DeviceKey
- ✅ 模型绑定信息

### 真正的问题是数据源

**你的 app 数据库中没有 nRF Mesh 配网的设备**

```
问题链:
1. nRF Mesh app 配网设备 → 保存到 nRF Mesh 数据库
2. 你的 app 有自己的数据库 → 没有这些设备
3. 你的 app 导出 → 只导出自己数据库中的设备
4. 导出的 JSON 不包含 nRF Mesh 配网的设备
```

### 解决方案

**不是修改导出功能，而是同步数据**：

1. **方案 A：导入 nRF Mesh 配置**
   ```
   nRF Mesh app → 导出 JSON → 你的 app 导入
   ```

2. **方案 B：在你的 app 中配网**
   ```
   你的 app → 配网设备 → 自动保存到数据库 → 导出包含所有设备
   ```

3. **方案 C：共享数据库**（不推荐，复杂且容易出错）
   ```
   两个 app 使用同一个 Mesh 数据库
   ```

```kotlin
fun canExport(): Pair<Boolean, String> {
    val network = MeshState.meshNetWork
    if (network == null) {
        return Pair(false, "网络未加载")
    }
    
    if (network.nodes.isEmpty()) {
        return Pair(false, "没有已配网设备")
    }
    
    if (network.netKeys.isEmpty()) {
        return Pair(false, "没有 NetKey")
    }
    
    if (network.appKeys.isEmpty()) {
        return Pair(false, "没有 AppKey")
    }
    
    return Pair(true, "可以导出")
}
```
